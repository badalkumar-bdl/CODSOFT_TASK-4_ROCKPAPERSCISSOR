# 🎮 Rock Paper Scissors – Python Console Game

This is a simple **Rock Paper Scissors** game built using **Python**, where a user plays against the computer in the terminal. The game continues until the user decides to stop, and keeps track of the score throughout the session.

---

## 🚀 Features
- Text-based interface for smooth interaction
- Randomized computer choice using Python's `random` module
- Real-time score tracking
- Input validation to handle invalid choices
- Option to replay the game after each round

---

## 📌 How It Works

1. The game starts with both user and computer scores set to 0.
2. The user is prompted to enter a choice: `rock`, `paper`, or `scissors`.
3. The computer randomly selects one of the three options.
4. The winner of each round is determined based on standard game rules:
   - Rock beats Scissors
   - Paper beats Rock
   - Scissors beats Paper
5. Scores are updated accordingly.
6. The user is given the option to continue or end the game.
7. On exit, the final score is displayed.
