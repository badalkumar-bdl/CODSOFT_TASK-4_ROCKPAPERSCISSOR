# 🎮 Rock Paper Scissors – Python Console Game

Welcome to the classic **Rock Paper Scissors** game – reimagined in Python! 🐍  
Play against the computer in a fun, interactive terminal-based experience that tracks your score and challenges your luck and logic.

---

## ✨ Features

- 🕹️ Interactive command-line interface  
- 🎲 Smart randomization using Python's `random` module  
- 📈 Real-time score tracking  
- 🔁 Replay functionality for continuous gameplay  
- ⚠️ Input validation to handle mistakes  
- 🧠 Simple intelligent logic to determine the winner  
- 💬 Friendly and clear user feedback  

---

## 🧠 Intelligent Game Logic

This game simulates decision-making using Python conditionals.

- If the user and computer choose the same, it's a **tie**.  
- Otherwise, it evaluates winning rules such as:  
  - Rock beats Scissors  
  - Scissors beats Paper  
  - Paper beats Rock  

Each round's result is computed based on these rules, and the score is updated in real time.
